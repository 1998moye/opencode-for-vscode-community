# 品牌资源说明

扩展市场图标 `icon.png` 与 `icon-source-dark.svg` 来自 [OpenCode 官方品牌页](https://opencode.ai/brand)（仓库内路径参考：`anomalyco/opencode` 的 `opencode-logo-dark-square` 资源）。

活动栏图标 `activity.svg` 为上述方形标识的单色 `currentColor` 变体，以适配 VS Code 深浅主题。

活动栏使用 `activity.svg`（`currentColor`，随侧栏主题着色）。

编辑器标题栏使用 `chat-light.svg` / `chat-dark.svg` 与 `opencode-mark-*.svg`：固定高对比色（天蓝 `#38bdf8` / `#0284c7`），避免 `currentColor` 与标题栏背景糊在一起。

本扩展与 OpenCode 官方无隶属或背书关系；使用官方标识时请遵守其品牌指南。
